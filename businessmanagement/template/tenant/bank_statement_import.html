Instrucciones de importación

El archivo CSV debe contener las siguientes columnas (encabezados):

  • fecha o date - Fecha de la transacción (formato: YYYY-MM-DD o DD/MM/YYYY)
  • monto o amount - Valor de la transacción (número positivo)
  • moneda o currency - Moneda (COP, USD, EUR) - opcional
  • descripcion o description o concepto - Descripción del movimiento - opcional
  • referencia o external_id - Número de referencia - opcional

Notas:

  • Los montos negativos (egresos) se detectan automáticamente si hay signo menos
  • El separador puede ser comma (,) o punto y coma (;)
  • Si选择 "El CSV tiene encabezado", la primera fila se ignorará

Ver ejemplo de CSV

fecha,monto,moneda,descripcion,referencia
2026-06-01,1500000.00,COP,Pago cliente #101,REF-001
2026-06-02,-250000.00,COP,Pago proveedor,REF-002
2026-06-03,500.00,USD,Comisión mensual,COM-001
